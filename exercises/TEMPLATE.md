# 练习模板

每个练习应该包含以下文件：

## 目录结构
```
exercises/
└── YYYY-MM-DD_练习名称/
    ├── README.md           # 练习说明和笔记
    ├── 源代码文件.c         # C源代码
    └── (可选) 其他文件
```

## README.md 模板

```markdown
# [练习名称]

## 目标
[描述这个练习的学习目标]

## 代码说明
[解释代码的主要功能和知识点]

## 编译和运行
```bash
gcc 源文件.c -o 输出文件
./输出文件
```

## 预期输出
```
[程序的预期输出]
```

## 学习笔记
- [知识点1]
- [知识点2]
- [遇到的问题和解决方案]
```

## 源代码模板

```c
#include <stdio.h>

/*
 * 练习：[练习名称]
 * 日期：YYYY-MM-DD
 * 描述：[简短描述]
 */

int main() {
    // 你的代码
    
    return 0;
}
```

## 命名建议

- 日期格式：YYYY-MM-DD (例如：2025-11-16)
- 练习名称：使用英文或拼音，用下划线连接 (例如：hello_world, array_basics)
- 完整示例：`2025-11-16_hello_world`
