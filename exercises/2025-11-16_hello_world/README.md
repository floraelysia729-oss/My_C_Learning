# Hello World 练习

## 目标
学习C语言的基本程序结构和printf函数的使用。

## 代码说明
这是一个简单的C程序，演示了：
- 包含标准输入输出库 `#include <stdio.h>`
- 主函数 `main()` 的基本结构
- 使用 `printf()` 函数输出文本

## 编译和运行
```bash
gcc hello.c -o hello
./hello
```

## 预期输出
```
Hello, World!
```

## 学习笔记
- `printf()` 函数用于格式化输出
- `\n` 是换行符
- `return 0` 表示程序正常结束
