# 学习笔记

这个目录用于存放C语言学习过程中的笔记和反思。

## 建议的组织方式

### 按主题组织
```
notes/
├── 01-基础语法/
│   ├── 数据类型.md
│   ├── 运算符.md
│   └── 控制结构.md
├── 02-函数/
│   ├── 函数定义.md
│   └── 递归.md
└── 03-指针/
    └── 指针基础.md
```

### 按日期组织
```
notes/
├── 2025-11-week1.md
├── 2025-11-week2.md
└── 2025-12-week1.md
```
